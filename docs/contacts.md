# Contacts and exports

## Capture and review

| Source | What to expect |
| --- | --- |
| Business card photos | Choose **Upload business cards** and select one or more images. CardCap adds the contacts for review and can merge matching cards. |
| Website | Choose **Add a domain**. Review the suggested contact alongside the source page, then save it. A company name is enough when the site lists no individual. |
| Email signature or copied text | Choose **Paste an email signature** and paste the relevant lines. Review the draft before saving. |
| Existing contact file | Use **Import** to bring in CSV, vCard, or JSON contacts. The import summary shows new and merged records. |

In the dashboard’s contact list, choose **Show → Needs review** to find records that need attention. Open a contact to correct its fields, add notes or a next step, and mark it reviewed.

## Choose an export

**Export** downloads your account’s collection, including contacts outside the current search or filter.

| Format | Use |
| --- | --- |
| CSV | Import into a CRM or spreadsheet. Includes contact details, tags, status, next step, and notes. When the collection includes text or website captures, it also includes source URL and capture time columns. |
| iContact CSV | Import into iContact using its column names. The first phone goes in Phone and additional numbers go in Notes. |
| vCard | Import into an address book. |
| JSON | Work with structured contact records. |
| HTML | Browse a standalone contact list. |
